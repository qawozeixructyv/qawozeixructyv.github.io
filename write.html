A ROOM TO WRITE

写一篇。

先写下来。标题、段落和句子，都可以之后再改。

草稿只保存在当前浏览器。导出 Markdown 是备份；输入限定权限的 GitHub Token 后，可点击发布到博客。

照片与文章封面
也可以把图片拖到这里，或粘贴到正文框

先在下方输入 Token。上传图片会立即进入公开仓库并同步到画廊，正文仍需点击发布。支持 JPG、PNG、WebP、GIF，单张最多 8 MB。

当前正文中的图片

删除只移除正文中的这一次插入。发布更新后生效；已上传文件和画廊照片保留。

文章音频（默认不播放）

单个最多 20 MB。上传文件会公开；发布文章后，封面卡片显示音频提示，读者展开播放器后手动播放。

发布文章和媒体
  1. 输入仅授权博客仓库的 Token。
  2. 上传照片，点「插入正文」放到光标处，或点「设为封面」；音频可从音频区域上传。
  3. 写完点击「发布到博客」。图片和画廊、文章页面在 Pages 构建成功后更新。
