A ROOM TO WRITE

写一篇。

先写下来。标题、段落和句子，都可以之后再改。

草稿只保存在当前浏览器。导出 Markdown 是备份；发布到博客还需要上传到 GitHub。

尚未开始0 字

文章导出后，放入仓库的 _posts 文件夹。照片需另行上传到 assets/images；工具不会自动上传或公开正文。

发布到 GitHub：三步
  1. 导出文章 .md 文件。
  2. 打开 仓库的 _posts 文件夹，选择 Add file → Upload files，上传文章并提交。第一次需要先创建仓库并上传博客文件。
  3. 等待 GitHub Pages 构建完成，刷新博客即可。未来日期的文章默认不会发布。
